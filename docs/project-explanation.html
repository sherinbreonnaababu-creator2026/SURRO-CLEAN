EcoSanctuary AI - Smart Waste & Sanitization Management Frontend

1. Project Overview

This project is a smart city frontend dashboard designed to improve urban cleanliness, waste management, and public sanitation. It gives a municipal admin or city worker a single control panel where they can monitor garbage bins, identify overflowing bins, manage route planning for garbage collection trucks, and track public hygiene conditions.

The app is built as a frontend prototype for SIH (Smart India Hackathon) and focuses on real-world smart city problems. It uses mock data to simulate IoT sensors, citizen complaints, route planning, waste classification, analytics, and sanitation operations.

The main goal of the project is to show how technology can make city services faster, cleaner, and more efficient.

2. Problem Solved

In many cities, waste management is still done manually. Common issues include:

  • bins becoming full without being noticed
  • collection trucks taking inefficient routes
  • unsegregated waste causing pollution
  • citizens having no easy way to report dirty areas
  • poor sanitation in public facilities
  • no proper monitoring of waste trends or impact

This project solves these problems by creating a digital command center for handling waste and sanitation efficiently.

3. Frontend Structure

The project is built using React and Vite. It uses reusable components and state to manage different sections of the application. The interface is designed like a futuristic smart-city dashboard with dark theme, green/cyan accents, glass panels, KPI cards, charts, and role-based navigation.

4. Detailed Features

Feature 1: Navigation Bar and Role Switching

The top navigation bar acts like a smart-city home shell. It contains the app logo, navigation tabs, role switcher, and critical alerts. Different personas such as admin, citizen, driver, and inspector can operate within the same system.

Feature 2: Command Center Dashboard

This is the main landing screen. It provides a quick summary of cleanliness, smart bins, AI accuracy, fleet efficiency, and sanitation compliance. It is designed to help administrators see system health at a glance.

Feature 3: AI Waste Classifier

This section simulates a vision model for waste segregation. Users can select sample waste items, upload custom images, and scan them to identify categories such as wet waste, dry recyclable waste, e-waste, or hazardous waste. The app then shows confidence scores and reward points for correct segregation.

Feature 4: Smart Bin Monitoring System

This is the IoT bin management feature. It displays location, fill percentage, status, gas level, temperature, and battery. Users can simulate sensor data, trigger compaction, and lock bins in emergency cases. This helps detect dangerous conditions such as overfull bins or gas buildup.

Feature 5: Route Optimization and Green Fleet Management

This section presents waste collection route planning. Trucks are assigned priorities based on bin fill levels. Users can mark bins as collected to reduce waste and improve route efficiency. The system emphasizes reduced fuel use and lower carbon emissions.

Feature 6: Citizen Portal and Grievance Reporting

Citizens can report local sanitation problems, choose issue category and priority, and submit a complaint. Each valid report earns GreenPoints. The portal also contains a reward market and leaderboard to encourage public participation.

Feature 7: Sanitization Monitor

This section tracks hygiene in public facilities. It monitors water tank levels, soap levels, odor, footfall, and cleanliness score. It can trigger UV-C disinfection cycles and allows user feedback to judge overall facility quality.

Feature 8: Analytics Dashboard

The analytics page shows charts for waste inflow, recycling distribution, landfill diversion, revenue generation, and carbon savings. It turns data into actionable information for city leaders.

Feature 9: Alerts and Notifications

The app uses toast notifications and status updates to create a responsive experience. These keep the user informed of critical events, report success, fleet dispatches, and report exports.

5. Learning Value

This project helps a student learn multiple frontend and software engineering concepts, including React components, state management, conditional rendering, forms, charts, notification handling, and product design. It is a strong beginner-to-intermediate project because it combines real-world problem solving with UI/UX design.

6. Final Summary

EcoSanctuary AI is a smart city waste and sanitation dashboard that uses modern frontend technology to improve cleanliness in urban environments. It integrates smart bin monitoring, AI waste sorting, route optimization, citizen complaints, sanitation tracking, and analytics dashboards. Even though it is a frontend prototype, it effectively communicates the full vision of a real smart-city system.
